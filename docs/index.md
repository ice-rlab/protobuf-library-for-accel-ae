# Protobuf Acc Docs

Hello 👋, welcome to the Protobuf accelerator docs. 

> [!NOTE]
> These docs are specific to the repo [github.com/ice-rlab/protobuf-library-for-accel-ae](https://github.com/ice-rlab/protobuf-library-for-accel-ae) which is a fork of the repo [github.com/sagark/protobuf-library-for-accel-ae](https://github.com/sagark/protobuf-library-for-accel-ae).
